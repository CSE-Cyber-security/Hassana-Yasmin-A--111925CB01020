Simple Calculator Application

1. Project Title

Design and Develop a Simple Calculator using Python

2. Objective

To develop a simple calculator application using Python that performs basic arithmetic operations. This project also helps in learning how to upload source code, maintain commits, and document a project using GitHub.

3. Project Description

The Simple Calculator is a beginner-friendly Python application that accepts two numbers from the user and performs arithmetic operations based on the user's choice. It displays the calculated result clearly.

The calculator supports the following operations:

- Addition (+): Adds two numbers.
- Subtraction (-): Subtracts the second number from the first number.
- Multiplication (*): Multiplies two numbers.
- Division (/): Divides the first number by the second number.

The application repeats the menu after each operation, allowing users to perform multiple calculations until they choose to exit.

4. Technologies Used

- Programming Language: Python
- Version Control: Git
- Repository Hosting: GitHub
- Code Editor: Visual Studio Code (or any Python-supported editor)

5. Features

- Performs four basic arithmetic operations.
- Accepts user input.
- Displays results clearly.
- Repeats the menu until the user exits.
- Handles invalid menu choices.
- Prevents division by zero.
- Simple and easy-to-use interface.

7. How to Run the Program

Step 1: Install Python

Install Python on your computer if it is not already installed.

Step 2: Clone the Repository

git clone https://github.com/YOUR-USERNAME/Simple-Calculator.git

Replace "YOUR-USERNAME" with your GitHub username.

Step 3: Open the Project Folder

cd Simple-Calculator

Step 4: Run the Program

python calculator.py

If your system uses "python3", run:

python3 calculator.py

10. Git Commands Used

Initialize the Git repository:

git init

Add project files:

git add .

Commit the changes:

git commit -m "Initial commit: Simple Calculator"

Connect the GitHub repository:

git remote add origin https://github.com/YOUR-USERNAME/Simple-Calculator.git

Rename the branch to "main":

git branch -M main

Upload the project to GitHub:

git push -u origin main

For future updates, use:

git add .
git commit -m "Update calculator application"
